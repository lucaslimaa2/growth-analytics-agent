# Growth Analytics Agent

Project #2 of Lucas Lima's AI portfolio.

A single-page web app combining a fixed growth-metrics dashboard with a chat
agent that autonomously queries a synthetic SaaS dataset (Supabase Postgres),
runs analyses (cohort, funnel, period-over-period, segment breakdown),
generates interactive Plotly charts, and returns insights with concrete
recommendations.

Built with Python 3.12, the Anthropic SDK (Claude Haiku 4.5), Supabase,
Plotly, and vanilla HTML/CSS/JS, deployed on Vercel.
